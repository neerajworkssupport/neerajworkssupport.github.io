NEERAJ WORKS PORTFOLIO — GITHUB PAGES SETUP

1. Sign in at https://github.com/
2. Click + (top right) > New repository.
3. Repository name must be neerajworkssupport.github.io IF your GitHub username is exactly neerajworkssupport.
   If your username differs, use YOURUSERNAME.github.io (all lowercase).
4. Set visibility to Public and create the repository.
5. In the new repository, click Add file > Upload files.
6. Upload index.html from this folder. (README.txt is optional.)
7. Click Commit changes.
8. Open repository Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Choose branch main and folder /(root), then click Save.
11. Wait for the deployment to finish. Open https://YOURUSERNAME.github.io/
    (replace YOURUSERNAME with your exact GitHub username).
12. If it does not appear, open the Actions tab to check the Pages deployment status.

IMPORTANT:
- Public repositories and their contents are visible to everyone.
- This is a static site; it does not contain a backend or a contact form.
- Wallpaper app link is already included.
- Amrit Mala is marked "In development" and should only be changed when its release status is accurate.
- Contact section currently links to your existing wallpaper information/privacy page because no public support email was supplied.
